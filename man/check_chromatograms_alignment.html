Check multi-detector chromatogram alignment

Description

Visualizes and aligns BPI, CAD, and PDA chromatograms across positive and/or negative ionization runs after optional Fourier noise filtering, peak sharpening, and baseline correction.

Usage

check_chromatograms_alignment(
  file_negative = NULL,
  file_positive = NULL,
  time_min = 0.5,
  time_max = 32.5,
  cad_shift = 0.05,
  pda_shift = 0.1,
  fourier_components = 0.01,
  frequency = 1,
  resample = 1,
  chromatograms = c("bpi_pos", "cad_pos", "pda_pos"),
  headers = c(bpi = "BasePeak_0", pda = "PDA#1_TotalAbsorbance_0", cad = "UV#1_CAD_1_0"),
  type = "baselined",
  normalize_intensity = TRUE,
  normalize_time = FALSE,
  show_example = FALSE,
  intensity_floor = 0.001,
  k2 = 250,
  k4 = 1250000,
  sigma = 0.05,
  smoothing_width = 8,
  baseline_method = "peakDetection",
  improve_signal = TRUE
)

Arguments

file_negative Path to negative-mode .mzML file (optional).
file_positive Path to positive-mode .mzML file (optional).
time_min Minimum retention time in minutes. Default is 0.5.
time_max Maximum retention time in minutes. Default is 32.5.
cad_shift CAD retention time shift in minutes, or “auto” / NULL to estimate the optimal shift via FFT cross-correlation against the MS BPI trace. Default is 0.05.
pda_shift PDA retention time shift in minutes, or “auto” / NULL to estimate the optimal shift via FFT cross-correlation against the MS BPI trace. Default is 0.1.
fourier_components Fraction of Fourier components to retain. Default is 0.01.
frequency Acquisition frequency in Hz. Default is 1.
resample Resampling factor. Default is 1.
chromatograms Character vector of chromatograms to plot. Default is c(“bpi_pos”, “cad_pos”, “pda_pos”).
headers Named character vector mapping detector types (“bpi”, “pda”, “cad”) to .mzML chromatogram header IDs.
type Type of chromatogram to display: “baselined” or “improved”. Default is “baselined”.
normalize_intensity Logical; normalize intensity to [0, 1]. Default is TRUE.
normalize_time Logical; normalize time to [0, 1]. Default is FALSE.
show_example Logical; use bundled example data. Default is FALSE.
intensity_floor Small positive value for intensity floor. Default is 0.001.
k2 Second-derivative weight for signal sharpening. Default is 250.
k4 Fourth-derivative weight for signal sharpening. Default is 1250000.
sigma Gaussian sigma for signal sharpening. Default is 0.05.
smoothing_width Moving-average window width for derivative smoothing. Default is 8.
baseline_method Baseline correction method passed to baseline::baseline(). Default is “peakDetection”.
improve_signal Logical; apply Fourier filtering and sharpening. Default is TRUE.

Value

A plotly htmlwidget displaying the aligned chromatograms.

Examples

library("cascade")

check_chromatograms_alignment(show_example = TRUE)
check_peaks_integration
