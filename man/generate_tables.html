Generate interactive HTML and TSV summary tables of annotated peaks

Description

Integrates peak-informed features across positive and/or negative modes with TIMA structural annotations and LOTUS taxonomic/literature metadata to produce both an interactive HTML table (with 2D chemical structure depictions via CDK Depict) and a tab-separated summary table.

Usage

generate_tables(
  annotations = NULL,
  file_negative = NULL,
  file_positive = NULL,
  min_confidence = 0.4,
  show_example = FALSE,
  export_csv = TRUE,
  export_html = TRUE,
  export_dir = "data/processed",
  export_name = "cascade_table"
)

Arguments

annotations Path to TIMA annotations .tsv file (optional when show_example = TRUE).
file_negative Path to negative-mode informed features .tsv file (optional).
file_positive Path to positive-mode informed features .tsv file (optional when show_example = TRUE).
min_confidence Minimum final annotation confidence score. Default is 0.4.
show_example Logical; use bundled example data. Default is FALSE.
export_csv Logical; export .tsv summary table. Default is TRUE.
export_html Logical; export .html interactive gt table. Default is TRUE.
export_dir Directory where output files are written. Default is “data/processed”.
export_name Base filename (without extension) for exported tables. Default is “cascade_table”.

Value

A named list with two elements:

  • pretty_table: A gt_tbl interactive table object.

  • csv_table: A data.table containing the formatted summary rows.

Examples

library("cascade")


generate_tables(show_example = TRUE, export_csv = FALSE, export_html = FALSE)
