Check chromatographic peak detection and integration bounds

Description

Detects, fits (via Exponential-Gaussian Hybrid or Gaussian nonlinear least squares), and trapezoidally integrates peaks in a detector chromatogram (CAD, BPI, or PDA), links them to MS features, and returns an interactive plotly visualization showing the signal, detected peak maxima, and start/end integration bounds.

Usage

check_peaks_integration(
  file = NULL,
  features = NULL,
  detector = "cad",
  chromatogram = "baselined",
  headers = c(bpi = "BasePeak_0", pda = "PDA#1_TotalAbsorbance_0", cad = "UV#1_CAD_1_0"),
  min_area = 0.005,
  min_intensity = 10000,
  shift = 0.05,
  show_example = FALSE,
  fourier_components = 0.01,
  time_min = 0.5,
  time_max = 32.5,
  frequency = 1,
  resample = 1,
  intensity_floor = 0.001,
  k2 = 250,
  k4 = 1250000,
  sigma = 0.05,
  smoothing_width = 8,
  baseline_method = "peakDetection",
  sd_max = 50,
  max_iter = 1000,
  noise_threshold = 0.001,
  fit = "egh",
  intensity_threshold = 0.1,
  improve_signal = TRUE
)

Arguments

file Path to .mzML file (optional when show_example = TRUE).
features Path to feature table (optional when show_example = TRUE).
detector Detector type: “cad”, “bpi”, or “pda”. Default is “cad”.
chromatogram Chromatogram processing stage: “original”, “improved”, or “baselined”. Default is “baselined”.
headers Named character vector mapping detector types to .mzML chromatogram header IDs.
min_area Minimum relative area fraction for peak filtering. Default is 0.005.
min_intensity Minimum MS intensity for feature filtering. Default is 1e4.
shift Retention time shift in minutes. Default is 0.05.
show_example Logical; use bundled example data. Default is FALSE.
fourier_components Fraction of Fourier components to retain. Default is 0.01.
time_min Minimum retention time in minutes. Default is 0.5.
time_max Maximum retention time in minutes. Default is 32.5.
frequency Acquisition frequency in Hz. Default is 1.
resample Resampling factor. Default is 1.
intensity_floor Small positive value for intensity floor. Default is 0.001.
k2 Second-derivative weight for signal sharpening. Default is 250.
k4 Fourth-derivative weight for signal sharpening. Default is 1250000.
sigma Gaussian sigma for signal sharpening. Default is 0.05.
smoothing_width Moving-average window width for derivative smoothing. Default is 8.
baseline_method Baseline correction method passed to baseline::baseline(). Default is “peakDetection”.
sd_max Maximum standard deviation for peak filtering. Default is 50.
max_iter Maximum iterations for peak fitting. Default is 1000.
noise_threshold Noise threshold for peak detection. Default is 0.001.
fit Peak fitting model: “egh”, “gaussian”, or “raw”. Default is “egh”.
intensity_threshold Minimum normalized intensity threshold for peak filtering. Default is 0.1.
improve_signal Logical; apply Fourier filtering and sharpening. Default is TRUE.

Value

A plotly htmlwidget showing the chromatogram and detected peak boundaries.

Examples

library("cascade")

check_peaks_integration(show_example = TRUE)
check_chromatograms_alignment
process_compare_peaks
